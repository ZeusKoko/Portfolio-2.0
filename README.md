## ✨ Key Features

- **Mouse-Scrubbed Background Video**: Full-screen video mapped to horizontal cursor velocity (`SENSITIVITY = 0.8`) with seek-flooding prevention via an `onSeeked` queue mechanism. Also supports touch swipe navigation on mobile devices.
- **A.R.I.A Typewriter Engine**: Custom React `useTypewriter` hook with delayed initialization and animated step-end blinking cursor.
- **Independent Action Pills**: Fast-access controls that animate into view 400ms after load with 1-click clipboard email copying (`kokonyazeus@gmail.com`).
- **Signature Sweatshirt Olive Palette**: The header typography and mobile hamburger controls utilize `#7D8D56`, sampled directly from Zeus's signature sweatshirt and the "CREATIVE DEVELOPER" hero branding.

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/ZeusKoko/portfolio.git

# Navigate to the project directory
cd portfolio

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Vite development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Building for Production

```bash
npm run build
```
